# Nifty 50 Index Scalper (Android APK)

## How to Generate Your APK on GitHub (3 Steps)
1. Upload all files in this folder to a new GitHub repository on the `main` branch.
   - **Important if using GitHub Web Upload:** Make sure `.github/workflows/build-apk.yml` is included (if your OS hides `.github`, click **Add file > Create new file** on GitHub, name it `.github/workflows/build-apk.yml`, and paste its contents).
2. Open the **Actions** tab in your GitHub repository and wait ~3 minutes for **Build Nifty Scalper APK** to finish.
3. Click the completed workflow run, scroll to **Artifacts**, download **`nifty50-scalper-apk`**, unzip it, and install `app-debug.apk` on your Android phone.
